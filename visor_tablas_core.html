Estructura Relacional del Motor de Pruebas (7 Tablas)

Diseñado específicamente para automatizar la ejecución continua y control de calidad de todos los procedimientos del Core expuestos al Frontend o API Gateway:

core_test_objeto
Catálogo oficial de procedimientos PL/SQL con parámetros CLOB, schemas JSON de validación y payloads ejemplo.
core_test_suite
Agrupaciones de pruebas por batería: Smoke Tests, Regresión Transaccional, Módulo de Autenticación, etc.
core_test_caso
Escenarios parametrizados con su p_json_entrada exacto, resultado esperado y SLAs de rendimiento.
core_test_asercion
Reglas de validación granular sobre el p_json_salida mediante JSON Path ($.codigo, $.data.id).
core_test_ejecucion
Cabecera histórica de ejecuciones (Test Runs), fecha, duración global, entorno (DEV/QA) y ejecutor.
core_test_detalle_ejecucion
Evidencia completa por caso: snapshot del JSON enviado, JSON retornado, tiempo ms y diffs.
core_test_mock_dato
Scripts SQL pre y post ejecución para sembrar o limpiar estados antes y después de cada prueba.
